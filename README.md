# Ecommerce Website

🎨 Our visual direction

The Wix template has a fairly fresh grocery-store aesthetic. We'll give ours a different identity.

Color palette

Instead of copying its visual treatment, we'll use:

Background     #F8F7F2   warm ivory
Primary        #173F35   deep forest green
Accent         #D9A441   muted gold
Text           #18221F   charcoal
Secondary      #E8EFEA   soft sage
White          #FFFFFF

So the overall feeling becomes:

premium + natural + modern + slightly editorial

rather than simply "grocery website."
